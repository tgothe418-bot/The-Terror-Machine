## Governing product decisions

- Main map: only story-important spaces and directed connections.
- Map density: compact opening map, with optional secondary regions stored as expandable-space anchors.
- The map must be both human-readable and machine-readable; the visual flowchart is derived from typed canonical data.
- New Forge Blueprints use an explicit starting node; they do not rely on array position.
- Cast receives explicit opening placement or deliberate offstage/nonlocal disposition; missing placement does not default everyone into the user's room.
- The model-backed Forge pass proposes a source-grounded opening aim for the selected user-controlled character.
- The user must explicitly accept that default, replace it with a creator-defined aim, or select **None declared**.
- The Engine receives the accepted aim as read-only orientation and never performs, rewrites, advances, or fills it in for the user.
- Every non-user cast member receives a reviewed pursuit or **No readable intent**. The latter is valid, especially for tertiary/quaternary figures.
- `cast.goals` is descriptive context, not independent initiative authority.
- Architect and extraction outputs are proposals. Only explicit user application mutates canonical `forgeDraft`.
- `CONTEXTUAL_DISCRETION` remains valid when genuinely chosen; it is never an automatic error fallback.
